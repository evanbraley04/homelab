# Technical Documentation

This directory contains the complete technical documentation for the Personal IT Homelab.

The documentation records the architecture, installation, configuration, networking, Docker services, remote access, DNS, HTTPS/TLS, monitoring, Windows Server, Active Directory, Group Policy, troubleshooting exercises, and lessons learned throughout the project.

## Files

### `Homelab-Technical-Documentation.pdf`

The complete formatted technical document.

This is the recommended version for reading the project as a finished technical report.

### `Homelab-Technical-Documentation.md`

The Markdown source version of the documentation.

This version is maintained alongside the PDF and provides a searchable, version-controlled representation of the project documentation.

## Scope

The documentation covers:

* Proxmox VE infrastructure
* Ubuntu Server administration
* Docker and Docker Compose
* Portainer
* Jellyfin
* Navidrome
* Nextcloud
* Kavita
* Caddy
* Pi-hole
* Tailscale
* Uptime Kuma
* Internal TLS/PKI
* Custom dashboard
* Windows Server
* Active Directory
* DNS
* Group Policy
* Domain authentication
* Account administration
* Troubleshooting
* Network architecture

The documentation is intentionally more detailed than the repository README. The README provides a concise overview, while this directory contains the complete technical record of the project.
