# Screenshots

This directory contains selected screenshots documenting the configuration and operation of the homelab.

The screenshots are organized by subsystem.

## Directory Structure

### `proxmox/`

Screenshots of the Proxmox virtualization environment, including:

* Proxmox dashboard
* VM/LXC inventory

### `jellyfin/`

Screenshots showing:

* Jellyfin dashboard
* Movie library
* Movie metadata

### `navidrome/`

Screenshots showing:

* Navidrome dashboard
* Music library
* Album metadata

### `nextcloud/`

Screenshots showing the Nextcloud application environment.

Personal files and private journal content are intentionally excluded.

### `kavita/`

Screenshots showing:

* Kavita dashboard
* Book/PDF metadata

### `pi-hole/`

Screenshots showing:

* Pi-hole dashboard
* Local DNS records

### `tailscale/`

Screenshots documenting the Tailscale environment.

Identifying information, email addresses, and network information that is not necessary for demonstrating the configuration have been redacted.

### `portainer/`

Screenshots showing:

* Portainer dashboard
* Docker container inventory

### `dashboard/`

Screenshots of the custom homelab dashboard.

### `caddy/`

Screenshots demonstrating the dashboard being accessed through its HTTPS hostname and Caddy reverse proxy.

### `windows-ad/`

Screenshots documenting the Windows/Active Directory lab, including:

* Active Directory users
* Security groups
* Organizational Units
* Workstations
* Group Policy Objects
* GPO configuration

## Purpose

The screenshots provide visual evidence of the infrastructure described in the technical documentation.

They are intentionally selective rather than exhaustive. The repository documentation contains the detailed configuration and troubleshooting history.
